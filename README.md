# SLD Generator

A web app that creates single line diagrams (SLDs) for solar PV installations.

## What it does now

User enters number of modules and how many inputs inverter has and app splits the strings evenly.

## Next

- Choose inverters, panels and batteries
- Generate the SLD drawing
- Export to PDF

## Built with

React + Vite

## Run it

    npm install
    npm run dev
